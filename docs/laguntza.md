# Uni Explorerren laguntza eta eskuliburua

Berrikuspena: 2026ko azaroaren 6a.

Testuinguruko laguntzak 23 gai biltzen ditu euskaraz eta gaztelaniaz: nabigazioa, profila, iragazkiak, haztapenak, interesa, konparatzailea, fitxak, kostuak, mapak, QEDU, UNED, arte irakaskuntzak eta atzerriko titulazioak. Plazak, hizkuntzak, praktikak eta fitxaren campus-iragazkia ere azaltzen ditu.

Hizkuntza bakoitzak berezko 55 pantaila-argazki zenbakitu ditu: ordenagailuko 27 eta mugikorreko 28. Mugikorreko irudiek benetako banaketa eta liburuaren botoia erakusten dituzte. Laguntzak mugikorreko irudiak aukeratzen ditu 690 px arte, eta Pantaila-argazkiak hautagailuaren bidez ikuspegiz alda daiteke.

Euskarazko edukia data/ayuda-contenido-eu.json fitxategian dago, JavaScript bertsioarekin batera. Irudiak assets/help-eu karpetan daude; mugikorrekoak, mobile azpikarpetan. Testuak, zenbakitutako markak eta irudiak batera berrikusi behar dira.

Euskarazko PDFa docs/manual-uni-explorer-eu.pdf da. Bi ikuspegiak, estekatutako aurkibidea eta laster-markak ditu. Pantaila luzeak hainbat orritan banatzen dira irakurketa errazteko. Adibideek ez dituzte iturri ofizialak edo datu bakoitzaren datak ordezten.

Laguntza kontsultatzeak ez ditu profila, hautaketa, iragazkiak edo ibilbidea aldatzen. Ixtean fokua jatorrizko kontrolera itzultzen da. Laguntzaren erabileraren eta PDFaren deskargaren gertaerak mantentzen dira.
